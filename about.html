ABOUT HYPER EDITOR

A focused workspace for files that matter.

HYPER EDITOR combines conversion, PDF utilities and document editing in a single local Flask application. The interface is intentionally simple while the editor workspace is built for detailed document work.

01

Convert

Move between common image, Office, text and PDF formats.

02

Edit

Work with PDF text, annotations, graphics and page structure.

03

Organise

Merge, split, rotate, extract, reorder and compress.
